# Proposed Extension (superseded)

`CSIM_ASX.rdf` in this folder is the original **v0.0.1** draft of the ASX
ontology (2026-01-20). It is kept for history only.

The live ASX ontology is in the repository's `Ontology/` folder:

- `Ontology/C2SIM_ASX-v004.rdf` - current version (v0.0.4)
- `Ontology/Archive/` - earlier versions
- `Ontology/asx004_merge.rdf` - C2SIM + SMX + LOX + ASX merged ontology
- `Derived products/ASX_Schema.xsd` - XML schema generated from the merge

Do not edit `CSIM_ASX.rdf`; make changes in `Ontology/`.
